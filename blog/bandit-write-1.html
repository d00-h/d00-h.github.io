LEVEL 0→1
readme 파일 읽기cat 명령어 기초
Goal
홈 디렉토리의 readme 파일에 다음 레벨 비밀번호가 있다.
풀이
cat readme
핵심 명령어
명령어설명
cat 파일명파일 내용을 출력
LEVEL 1→2
- 파일 읽기특수문자 파일명 처리
Goal
홈 디렉토리에 - 라는 이름의 파일에 비밀번호가 있다.
풀이
cat ./-
# '-' 는 특수문자라 현재 경로(./)를 명시해야 함
핵심 개념
명령어설명
./현재 디렉토리를 명시적으로 지정
LEVEL 2→3
공백 포함 파일명따옴표 또는 이스케이프 처리
Goal
파일 이름에 공백이 포함된 --spaces in this filename-- 파일을 읽어야 한다.
풀이
ls
# 파일명 정확히 확인
cat -- "--spaces in this filename--"
핵심 명령어
명령어설명
"파일명"공백 포함 파일명을 따옴표로 감싸기
--이후 인수를 옵션이 아닌 파일명으로 처리
LEVEL 3→4
숨김 파일 찾기ls -a 활용
Goal
inhere 디렉토리 안의 숨김 파일에 비밀번호가 있다.
풀이
cd inhere
ls -a
cat ...Hiding-From-You
핵심 명령어
명령어설명
ls -a숨김 파일(.으로 시작)까지 모두 표시
LEVEL 4→5
사람이 읽을 수 있는 파일file 명령어로 파일 타입 확인
Goal
inhere 디렉토리의 여러 파일 중 human-readable(ASCII text) 파일 하나에 비밀번호가 있다.
풀이
cd inhere
file ./-*
# ASCII text 인 파일 확인 → -file07
cat ./-file07
핵심 명령어
명령어설명
file 파일명파일 종류 확인 (ASCII text / data 등)
*와일드카드: 모든 파일에 적용
LEVEL 5→6
조건으로 파일 찾기find 명령어 활용
Goal
human-readable, 1033 bytes, not executable 조건을 만족하는 파일에 비밀번호가 있다.
풀이
cd inhere
find . -size 1033c ! -executable -type f
cat ./maybehere07/.file2
핵심 명령어
명령어설명
find . -size 1033c1033 bytes 크기의 파일 탐색
! -executable실행 불가능한 파일만
-type f디렉토리 제외, 파일만
LEVEL 6→7
서버 전체에서 파일 찾기소유자·그룹·크기 조건
Goal
서버 어딘가에 있는 파일: 소유자 bandit7, 그룹 bandit6, 크기 33 bytes
풀이
find / -user bandit7 -group bandit6 -size 33c 2>/dev/null
cat /var/lib/dpkg/info/bandit7.password
핵심 명령어
명령어설명
find /루트(/)부터 전체 탐색
-user / -group소유자 / 그룹 조건
2>/dev/null권한 없는 에러 메시지 숨기기
LEVEL 7→8
특정 단어 옆의 값 찾기grep 활용
Goal
data.txt 파일에서 "millionth" 단어 옆에 비밀번호가 있다.
풀이
grep millionth data.txt
핵심 명령어
명령어설명
grep 단어 파일파일에서 특정 단어가 포함된 줄만 출력
LEVEL 8→9
한 번만 등장하는 줄sort + uniq 파이프
Goal
data.txt에서 딱 한 번만 나오는 줄이 비밀번호다.
풀이
sort data.txt | uniq -u
핵심 명령어
명령어설명
sort알파벳 순으로 정렬
|파이프: 앞 명령어 결과를 뒤로 전달
uniq -u중복 없이 딱 한 번만 나오는 줄 출력
LEVEL 9→10
바이너리에서 문자열 추출strings + grep
Goal
data.txt는 바이너리 파일. = 기호 여러 개 앞에 비밀번호가 있다.
풀이
strings data.txt | grep "==="
핵심 명령어
명령어설명
strings바이너리 파일에서 사람이 읽을 수 있는 문자열만 추출
LEVEL 10→11
Base64 디코딩base64 -d
Goal
data.txt는 base64로 인코딩되어 있다.
풀이
base64 -d data.txt
핵심 명령어
명령어설명
base64 -dbase64 인코딩된 데이터를 디코딩
LEVEL 11→12
ROT13 복호화tr 명령어로 알파벳 치환
Goal
data.txt는 ROT13으로 암호화되어 있다. (알파벳을 13칸 이동)
풀이
cat data.txt | tr 'A-Za-z' 'N-ZA-Mn-za-m'
핵심 명령어
명령어설명
tr '원본' '변환'문자를 다른 문자로 치환
개념
ROT13: A→N, B→O ... 13칸씩 이동. 13번 두 번 = 원래 값으로 복원.
