LEVEL 12→13
hexdump + 반복 압축 해제xxd, gzip, bzip2, tar
Goal
data.txt는 hexdump 파일이며 내부가 여러 번 압축되어 있다.
풀이
mktemp -d
cd /tmp/tmp.xxxxxx
cp ~/data.txt .
xxd -r data.txt > data   # hexdump → 바이너리

# file로 종류 확인하며 반복
file data
# gzip이면:
mv data data.gz && gzip -d data.gz
# bzip2이면:
mv data data.bz2 && bzip2 -d data.bz2
# tar이면:
tar -xf data
# ASCII text 나올 때까지 반복 후:
cat data
핵심 명령어
명령어설명
xxd -rhexdump를 원래 바이너리로 변환
gzip -dgzip 압축 해제
bzip2 -dbzip2 압축 해제
tar -xftar 아카이브 해제

LEVEL 22→23

풀이

EOF

chmod 777 script.sh
chmod 777 /tmp/tmp.jWaVNMoX1K

# 1분 후
cat /tmp/tmp.jWaVNMoX1K/password.txt
